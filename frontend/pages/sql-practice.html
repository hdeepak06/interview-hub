Second Highest Salary

Aggregation & Subqueries

Requirement

Write an SQL query to find the second highest salary from the Employee table. If there is no second highest salary, return NULL.

Database Schema & Sample Data

Table: Employee
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+

Correct SQL Query

PostgreSQL / Standard SQL 
SELECT (
    SELECT DISTINCT salary 
    FROM Employee 
    ORDER BY salary DESC 
    OFFSET 1 LIMIT 1
) AS SecondHighestSalary;

Expected Query Result

+---------------------+
| SecondHighestSalary |
+---------------------+
| 200                 |
+---------------------+

Query Execution Explanation

The scalar subquery ensures that if the Employee table contains fewer than two distinct salaries, the outer SELECT statement evaluates to NULL as required.
