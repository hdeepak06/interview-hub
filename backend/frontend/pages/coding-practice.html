Reverse a String

Time: O(n) Space: O(n)

Problem Statement

Write a function that reverses an input string without using built-in reverse helpers.

Sample Input: 
"hello"
Sample Output: 
"olleh"

Reference Solution (Python)

Verified Reference
Python 3 
def reverse_string(s: str) -> str:
    char_list = list(s)
    left, right = 0, len(char_list) - 1
    while left < right:
        char_list[left], char_list[right] = char_list[right], char_list[left]
        left += 1
        right -= 1
    return "".join(char_list)

Algorithm & Edge Cases

Two-pointer technique swapping characters in-place from the outer ends toward the center until pointers cross.

Edge cases handled: Empty strings, single-character strings, strings with special symbols and whitespace.
