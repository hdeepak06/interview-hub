**Tagline:** Learn. Practise. Test. Get Interview Ready.

---

## 1. Executive Summary

Deepak Interview Hub is an engineering interview preparation platform engineered specifically for:
- BE Computer Science Engineering (CSE) students
- BE Information Science Engineering (ISE) students
- BE Artificial Intelligence and Machine Learning (AIML) students
- Engineering freshers and entry-level software developer candidates

The platform is strictly **company-independent** and avoids company-specific question collections, focusing instead on core computer science foundations, algorithmic programming, relational database engineering, software design, and placement viva examinations.

## 3. Strict Three-Tier Difficulty System

Every question, exercise, and mock assessment adheres to three distinct difficulty levels:
1. **Easy:** Fundamental definitions, baseline syntax, standard library behavior, introductory problems.
2. **Medium:** Applied engineering, edge cases, standard technical interview coding problems, multi-table queries.
3. **Difficult:** System internals, memory models, concurrent transactions, deadlock handling, complex time-space trade-offs.

---

## 4. Key Platform Features

1. **Authentication & Student Profiles:** Branch-specific registration (CSE, ISE, AIML, Other), role-based permissions, token authentication.
2. **Question Bank Engine:** Real-time search, subject and difficulty filtering, accordion solutions, verified code samples, and interview tips.
3. **Timed Mock Test Simulator:** Configurable test parameters, live countdown timer, question palette navigation, review flagging, and server-side grading.
4. **Data-Driven Dashboard:** Real-time aggregation of student attempts, learning streak calculation, accuracy percentage, and difficulty distribution without hardcoded numbers.
5. **Interactive Practice Modules:** Python coding problem sandbox with complexity analysis, SQL query challenges with schemas and sample data, and placement aptitude problems with mathematical proofs.
