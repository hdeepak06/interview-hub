# DEEPAK INTERVIEW HUB — Question Content Guidelines

---

## 1. Principles of Technical Question Integrity

Every question published on Deepak Interview Hub must adhere to strict quality benchmarks:
1. **Never use placeholder questions:** Questions like "What is Python?" with one-line answers are strictly rejected.
2. **Never use generic or ambiguous answers:** Answers must be unambiguous, technically rigorous, and directly answer the exact question.
3. **Four Meaningful Choices:** MCQ questions must have four plausible, technically grounded options with exactly one correct option.
4. **Detailed Explanations:** Explanations must explain *why* the correct answer is correct and *why* the common distractors are incorrect.
5. **Practical Code Examples:** Questions dealing with syntax, algorithms, or runtime behavior must include copy-pasteable, verified code examples with exact terminal output.
6. **Interview Tips:** Each question must provide practical interview coaching (e.g. edge cases to highlight, alternative approaches, or follow-up questions interviewers typically ask).

---

## 2. Content Review Workflow

```
[Draft] ──(Technical Check)──> [Reviewed] ──(Content Lead Approval)──> [Approved] ──(Release)──> [Published]
```

Only questions with status `published` are exposed to student clients.
